# Create your PRD and task backlog

Ralphdex keeps all of its state on disk under `.ralph/` so any session can resume from inspectable files instead of chat history.

The **PRD Wizard** scaffolds that state for you: it drafts a product brief (`.ralph/prd.md`) and a starter task backlog (`.ralph/tasks.json`) from a short description of what you want to build.

You only need to do this once per workspace. After it exists, Ralphdex reads and updates these files as it works.
